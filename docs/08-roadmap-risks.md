# 08 · 路线图与风险

> 发展路线图已独立为仓库根 **`ROADMAP.md`**（含当前基线盘点、P0–P2 规划、搁浅模块清点）。本文档只保留风险台账。

## 风险与缓解

| 风险 | 影响 | 缓解 |
|---|---|---|
| 搁浅模块腐化 | core 中 52 个已实现函数（collab/history/animation/prototest）长期无调用方，与核心语义漂移 | ROADMAP P0-1：边界补齐前以白盒测试锚定行为；每项出井需带 CLI/MCP 入口 + 测试 |
| classic wasm 写路径复杂度 | 字符串分配辅助若设计不当，GC 不认识宿主写入的裸指针 | 只暴露“分配+填充”两步原语，对象构造全在引擎侧；契约测试锁定往返 |
| 双向同步一致性 | 多 Agent 并发编辑同源冲突/丢单 | 串行 + revision 乐观锁（当前）；collab OT 模块出井后切换三方合并 |
| 性能回归 | 布局/渲染随组件库扩张劣化 | benchmark 进 CI（P2-10），节点数/深度/Fill 密度基线告警 |
| 分发渠道单点 | npm 风控曾拦截 win32 包 | 双渠道：GitHub Releases 全产物归档（engine-v* tag 自动）已落地 |
| MoonBit 工具链演进 | minor 版本行为差异 | CI 用 latest + 179 测试 + CLI/MCP 冒烟挡板；已发布产物冻结不受影响 |
| LLM 输出不稳定 | Agent 声明写错 | 声明 DSL 面小 + moon check 秒级反馈 + 结构化违规回灌 + AgentGate 零容忍 |
| 前端画布性能 | 大文档卡顿 | 增量解析 + 布局脏区传播 + 渲染 diff；Playground 已用会话化编辑降低重建开销 |

## 验收基线

任何路线图条目的完成定义：**边界可达 + 测试锚定 + 文档同步 + 产物归档**，四者缺一不计完成。
