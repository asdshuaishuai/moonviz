六种集成方式

从命令行手动驱动，到 IDE 内 Agent 自动驱动——同一引擎，同一事实源。

CLI 行协议

换行分帧 JSON 协议。一个 CLI 进程 = 一个有状态 Project 会话。模板、操作、交互流、导出、渲染全覆盖。

Node SDK

@moonviz/engine-sdk：MoonViz 会话、Project 高层 API、DDP 加解密。纯传输层，不建第二事实源。

MCP Server

stdio JSON-RPC。read_mbt / render_mbt 源侧工具 + lint / critique / infer 设计智能工具，直接接入 MCP 客户端。

SKILL 技能

SKILL.md 定义 Agent 操作规范：双 Gate 语义、操作命令、约束红线，让任意 coding agent 安全驱动引擎。

DDP 文档分发

DDP1 = Argon2id + XChaCha20-Poly1305 加密容器；DDP2 = 免密压缩容器（zstd + CRC32）。Rust 编解码器独立交付。

Studio / Viewer

deepDesign Studio（Tauri）提供人类画布；ddpView（macOS 原生）只读查看加密 DDP 文档并渲染交互原型。

60 秒跑通

前置：安装 MoonBit 工具链（moon 可执行）。

# 1. 进入引擎目录
cd moonviz

# 2. 启动有状态 CLI 会话（stdin 逐行下发命令，stdout 逐行返回 JSON）
moon run --target native cli

# 3. 会话内构建一个双画板登录原型
template login t_login 390 844
template dashboard t_home 390 844
update t_login welcome_title text="欢迎回来"
flow t_login t_home login_btn
export-mbt-human          # ← HumanGate 校验 + 返回 canonical .mbt.md

# 4. 无会话渲染（AgentGate 级重载）
render-mbt-b64 <base64-mbt>

# 5. 打包 DDP 免密容器（Rust ddp_codec）
echo '{"operation":"encrypt","mbt_b64":"…","password":""}' | ddp/target/release/ddp_codec
